# Power BI Sales Dashboard

## Project Overview

This project presents an interactive sales dashboard developed using Microsoft Power BI to analyze sales performance and identify business trends.

## Objectives

* Analyze overall sales performance.
* Identify top-performing products and categories.
* Understand sales trends over time.
* Present key business insights through interactive visualizations.

## Tools and Technologies

* Microsoft Power BI
* Power Query
* DAX
* Data Visualization
* Data Cleaning and Transformation

## Key Insights

## Key Insights

1. **Leading Category:** Data Science ranked first among the displayed categories, attracting approximately 2.63 million viewers, followed by Computer Science and Business.

2. **Course-Type Popularity:** Traditional courses dominated the displayed course-type metric, with approximately 3.8 million in the sum of course IDs.

3. **Language Distribution:** English accounted for approximately 97.11% of the displayed language metric, indicating a strong concentration of English-language content.

4. **Subtitle Analysis:** Average viewer counts varied considerably across subtitle language counts, with the highest displayed value reaching approximately 86K.

5. **Course Duration:** The visible duration analysis showed a generally declining trend in average viewership across the displayed duration values.

6. **Skills Analysis:** Data Science had the highest average number of skills provided (4.74) among the five displayed categories, followed by Personal Development (4.47).

7. **Business Opportunity:** Further analysis of course ratings, completion rates, language preferences, and course duration could help identify opportunities to improve learner engagement.
